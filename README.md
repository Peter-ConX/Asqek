# Asqek — Professional Web Development

Modern, responsive one-page landing page website for **Asqek**, a web development service offering high-converting business websites.

## 🚀 Overview

- **Hero Section**: Value proposition, dual CTAs, urgency banner, and interactive browser mockup.
- **How It Works**: 3-step streamlined onboarding workflow.
- **Why Choose Us**: Feature highlights focusing on conversion, turnaround, and custom design.
- **Pricing Card**: Single spotlight package with $60 promotional rate and full feature checklist.
- **Portfolio / Showcase**: Recent and upcoming client work showcases (including FIRSTS ACADEMY).
- **Direct CTAs**: Side-by-side WhatsApp and Email inquiry actions.
- **Responsive Navigation**: Sticky header with glassmorphism and mobile drawer menu.

## 🛠️ Tech Stack

- **HTML5**: Semantic, accessible markup
- **CSS3**: Modern CSS custom properties (variables), Flexbox/Grid, fluid typography
- **JavaScript (Vanilla)**: Lightweight script for sticky header effects, mobile drawer, active navigation state, and smooth scrolling
- **Fonts**: Google Fonts ([Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans))

## 💻 Local Development

Simply clone the repository and open `index.html` in any modern web browser:

```bash
git clone https://github.com/Peter-ConX/Asqek.git
cd Asqek
# Open index.html in your browser
```
